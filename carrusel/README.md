# HGS · template carrusel curvo

Segunda opción de diseño del sitio HGS (estilo estudio suave, carrusel curvo en la portada).
Sitio estático generado con `python3 _build.py public` (ES en la raíz, EN en `/en/`).

- Contenido y textos: `_build.py`
- Estilos y animaciones: `assets/site.css`, `assets/site.js`
- Fotos: `img/` (sin rostro de Patricio, salvo la foto de equipo en Nosotros)
- Vercel: proyecto propio con Root Directory = `carrusel`.
